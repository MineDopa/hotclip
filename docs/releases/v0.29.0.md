# HotClip v0.29.0 — 搜到、听到、选成片

发布日期：2026-09-16

## 从搜索直接开始剪辑

- 台词与已扫描的画面证据按时间统一导航，可筛选全部、台词或画面。Enter / Shift+Enter 切换命中，第一次 Enter 定位第一项。
- 时间可靠时直接定位命中字词；估算时间有明确标记，旧词序与原文不一致时回退句级定位。
- 新增“试听上下文”，自动播放命中附近内容并停止，单次最多 30 秒。
- 点“选这段”即可打开预选完整命中句的选段窗口；画面命中会选择附近台词。确认后加入候选，支持撤销与重做。
- 长稿选段窗口只渲染视口附近的句子，筛选不丢已选内容，键盘焦点能正确进入和返回。

## 模型等待和长稿处理更稳

- 文字分析、画面研判和模型列表的超时覆盖响应头与正文，不再因服务只返回部分响应而无限等待。
- 短暂限流或服务忙时最多自动重试一次；等待中可取消。参数回退和空正文恢复共用文字请求的时限与限流重试额度。
- 明确的额度不足、鉴权失败、断网和超时不自动重发；服务端要求长等待时，文字分析会显示建议等待时长。
- 本地长稿预筛最多同时处理两段；失败或超时尚未处理的段落完整保留。
- 支持 IPv6 本机模型地址，按真实主机名识别本机服务；错误详情隐藏回显密钥，异常大响应会停止读取。

## 验证

1,278 项自动测试通过，1 项原有条件测试跳过；类型检查和生产构建通过。已实测浏览器搜索、试听、选段、撤销与 20,000 句长稿窗口，以及本机 HTTP 服务的限流恢复、超时、取消和并发上限。

无需新增模型或依赖，保留已有模型配置与项目数据。

# HotClip v0.29.0 — Search, listen, pick a clip

Release date: 2026-09-16

## Move from search to a clip

- Navigate speech and scanned visual evidence in chronological order, with All / Speech / Visuals filters. Enter and Shift+Enter move between matches; the first Enter seeks the first result.
- Seek directly to matched words when their timing is reliable. Estimated times are labeled; stale word mappings fall back to sentence timing.
- Play nearby context with automatic stopping and a 30-second cap.
- Pick this moment opens the picker with complete matched sentences selected. Visual evidence selects nearby speech. Confirm to add a candidate, then undo or redo as needed.
- The long-transcript picker renders only nearby rows, preserves selection during filtering, and restores keyboard focus correctly.

## More reliable model calls and long transcripts

- Text analysis, visual review and model-list deadlines cover response headers and body, including a service that stalls after a partial response.
- Transient rate limits or busy responses retry at most once, with cancellable waiting. Text parameter fallback and empty-content recovery share the original deadline and transient retry allowance.
- Recognized quota errors, authentication failures, network failures and timeouts are not automatically resent. Text analysis displays the suggested delay when a service requests a longer wait.
- Local screening handles at most two chunks concurrently and retains failed or unprocessed chunks when the deadline is reached.
- Local endpoint detection supports IPv6 and checks the actual hostname. Error details redact echoed credentials and oversized responses stop reading.

## Validation

1,278 automated tests passed, with one existing conditional skip; typecheck and production build passed. Browser checks covered search, context playback, clip selection, undo and a 20,000-sentence picker. Real localhost HTTP checks covered transient recovery, deadlines, cancellation and concurrency limits.

No new models or dependencies are required. Existing model settings and project data are preserved.
